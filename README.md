# In-Ear EEG Field Feasibility Study

Python/Jupyter Notebook scripts accompanying an MSc dissertation on low-channel in-ear EEG field feasibility.

## Repository contents

- `Script1_Independent_EEG_QC_Review_IC01_BG.ipynb`  
  Independent EEG quality-control review workflow.

- `Script2_Pilot8_EEG_SemiAutomatic_Batch_Processing.ipynb`  
  Pilot-stage semi-automatic EEG quality-control workflow.

- `Script3_Full_EEG_Processing_22Participants.ipynb`  
  Full EEG preprocessing and feature extraction workflow for the 22-participant dataset.

- `Script4_Final_Analysis_20Participants.ipynb`  
  Final EEG, ECG and POMS integration, statistical analysis and figure generation.

## Note

This repository contains analysis scripts only. No participant-level raw data are included.
